# Demo video

Put the video in this folder. Requirements (rules §6E and §10):

- 60 seconds at most, stored **inside** the repository. Git LFS is allowed; an external link alone is not enough.
- Show the real working product: what you built, the problem, how it works, the key workflow and the result.
- Frozen at 16:30 together with the code.
- Judged on working product, clarity and product insight. Production quality is not judged.
