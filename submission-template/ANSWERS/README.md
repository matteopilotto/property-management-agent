# ANSWERS

One folder per Reality Test case (rules §6C): `ANSWERS/1/ANSWER.md`, `ANSWERS/1/REASONING.md`, `ANSWERS/2/…`.

Together, the two files must make it possible to determine:

1. what the system received;
2. what actions it took;
3. what outputs or decisions it produced;
4. what it escalated;
5. what failed;
6. the final result for each case.

"We are interested in judgement and reasoning, not keyword matching."

Integrity (§6D): include logs or traces where practical; the file name and format are up to you. The results must be generated by the submitted system. "Do not manually replace failed agent outputs with corrected answers."

The rules fix only the two file names. The headings in `1/` are a suggestion.
