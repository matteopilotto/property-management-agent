# Agency playbook: maintenance Cases

Drawn from the 40 non-holdout public Property Management cases. At each decision point,
choose one Next Move: act, ask, wait or escalate. Text in quotes is verbatim system wording;
where it says "provider", read Contractor.

## 1. Landlord approval before a Contractor is chosen
- Do not instruct any Contractor until the Case shows Landlord approval. The system blocks the step with "Please complete landlord approval step first" or "Please approve selection of provider and category" (cases 011, 016, 033).
- To get approval, ask the Landlord in one message. Describe the fault and attach the Tenant's photos. Ask whether the Agency should send its Contractor ("resolve where possible, or quote if significant") or whether the Landlord will use their own (cases 016, 025, 028). At the same time, tell the Tenant the request is with the Landlord (cases 028, 033, 040).
- Treat any of these as approval:
  - a Landlord reply such as "Pls go ahead", "Yes please" or "👍" sent in answer to a request or quote (cases 007, 024, 032);
  - a Note recording a phone approval (case 002);
  - a prior agreement noted in the Case, e.g. "LL already agreed" (case 012);
  - the Update Event "Landlord approval confirmed. Proceed to provider selection." This is often the only trace (cases 004, 018, 031). If a Landlord reply already approves, do not wait for this Update.
- Telling the Landlord "I have raised a job" instead of asking happens on small routine repairs (cases 013, 030). Do it only when the Case records a standing instruction.
- On approval, act the same day: assign the Contractor and send the job to both the Contractor and the Tenant (cases 036, 042, 048).
- If the Landlord will use their own Contractor, instruct nobody. Wait on "Waiting for Landlord", chase the Landlord about progress, and close without payment once the Landlord confirms it is done (cases 028, 035, 045).
- If a diagnostic visit produces a quote, ask again: send the quote to the Landlord and instruct only on a clear yes (cases 002, 011, 033). Quote-first work on empty properties (check-out cleans, repaints) follows the same route (cases 004, 006, 007).
- If the Landlord lets the Tenant fix it, or suggests a workaround, pass that to the Tenant. Close when the Tenant confirms it is fixed (cases 014, 038, 049).
- The system waits "(3 days)" for a reply, then flags "No landlord/tenant response after 3 days. Please review manually." On that flag, re-send to the Landlord or phone them (ask) (cases 016, 019, 041).

## 2. Troubleshoot with the Tenant before a call-out
- If the fault may be user error, ask the Tenant to run simple checks before a Contractor is sent: a dishwasher checklist (case 012), oven settings from the manual (case 024), checking nothing is stuck in the drum (case 039), clearing the drain pump (case 041), a plunger and drain cleaner (case 027).
- If the report is vague, ask for photos or video, or for exactly which item is affected (cases 037, 044, 045).
- If the Tenant says the checks failed, move to Landlord approval or the Contractor (cases 012, 024). If the Tenant says it is fixed, close without payment (cases 027, 049).

## 3. Warn the Tenant when a call-out may be chargeable to them
- If the likely cause is the Tenant's use (internal drains blocked by hair or soap, foreign objects, damage), tell the Tenant before booking that this is their responsibility. Say that if a Tenant cause is found, the call-out and repair will be billed to them, and offer the option of booking their own plumber (case 027).
- Put the liability line in troubleshooting messages: "avoid the risk of being liable for an unnecessary call-out" (case 012).
- If damage might be the Tenant's, ask how it happened before instructing. If the Tenant credibly says it was already there, proceed as a Landlord repair (case 029).
- Give the Tenant a deadline, e.g. "if we do not hear back within 24hrs this request will be closed". If they stay silent, close with a Note (cases 027, 049).

## 4. Chase the Contractor and escalate repeated silence
- After instruction, the system sends reminder templates about 1, 3 and 6 days later, then flags "3+ reminders have been sent to provider. Please check what's happening." (cases 006, 018, 037). On that flag, send a personal email or make a call, not another template (cases 013, 030), then wait about 5 days (case 030).
- 2-3 days after a confirmed visit, the system flags "No work results; we need to check what is happening." Ask the Contractor for the outcome and the invoice (cases 012, 036, 048).
- If the Contractor missed the visit, rebook and wait (case 030).
- During long waits for parts, warranty or Contractor leave, chase every 2-7 days and log each chase (cases 025, 036). Tell the Tenant and the Landlord about each new date (cases 001, 036).
- Escalate when Contractor or Landlord silence continues after about 2 weeks of personal chasing, a booked visit fails twice, or the Landlord complains about delay (cases 019, 036).
- Never leave a Case on rolling holds with no chase (case 047 drifted for three months).

## 5. Check warranty before paying
- Before approving chargeable work, ask the installing Contractor about warranty if the item was fitted or repaired within about two years, or if the Tenant says it was replaced recently (case 025).
- Look past the 12-month installer warranty: a 2-year manufacturer warranty covered the oven (case 025). A Landlord may check the item's age and send it back to the fitting company himself (case 041).
- If a Contractor's own recent work fails again, it is redone at no charge. Get "no charge" in writing before closing (case 036).

## 6. Second quotes on large jobs
- If the Landlord asks for a second quote, get one. Present both side by side and state VAT explicitly (case 008: £1,370 with no VAT against £1,700 + VAT).
- If a quote is large or goes up, flag it and ask for approval again (case 019: £500 + VAT became about £600). State the minimum call-out cost up front (case 041: £65 + VAT).
- There is no fixed threshold. Single quotes up to about £600 were approved without comparison (cases 006, 007, 032).

## 7. Invoices: forward to the Landlord or deduct from rent
- When the Contractor confirms completion and sends the invoice, act. Follow the arrangement the Case shows: forward the invoice to the Landlord "for payment" with a one-line summary (cases 004, 007, 034), or tell the Landlord it will be deducted from the rent (cases 013, 018, 019).
- If the Landlord pays the Contractor directly, or the Contractor invoices the Landlord, record that and complete without payment (cases 001, 006, 030).
- If there is no charge (fault settled by itself, warranty, the Contractor's own fault), tell the Landlord and complete without payment (cases 016, 025, 036).
- If the invoice is lower than the quote, explain why when forwarding it (case 008). If it is higher than approved, ask the Landlord before treating it as payable.
- Chase a missing invoice while waiting for the Contractor (cases 005, 031, 042).
- If the Landlord has unpaid or slow invoices, confirm the Contractor still agrees to proceed, or ask for funds up front (cases 008, 019).

## 8. Holds: always give a reason and a date
- Every wait sets a dated follow-up with a reason that says what is awaited: "Waiting for Landlord", "Waiting for Provider", "Waiting for Tenant", or "Other" plus a specific comment (cases 001, 030, 039). Use "Other" for waits that belong to no one party: check-out works finishing (case 004), funds up front (case 019), the Landlord's own Contractor attending (case 045).
- Follow-up intervals seen: 3 days for a Landlord or Tenant reply; 1-3 days after instructing a Contractor; 2-3 days after a visit; weekly on long jobs with the Landlord's Contractor (cases 001, 045); a specific date when one is known, e.g. "follow up on Monday" (cases 001, 036).
- Choose the reason that matches who must act next.

## 9. Close only after final checks
- Close only with evidence the work is done: a Contractor completion message plus invoice, or a no-charge statement; for jobs they handled themselves, confirmation from the Landlord or Tenant (cases 028, 039, 049).
- Final checks, in order (cases 006, 013, 044): invoice and before/after photos uploaded or the reason they were skipped recorded; the Landlord informed or the invoice sent; key return checked and confirmed; then "All checks have been completed; the request is now closed".
- Ask for completion photos with the invoice; one Landlord complained when they were missing (case 036). Missing photos do not block closure if the reason is recorded (cases 004, 007).
- On empty properties, confirm the keys are back and the property is ready for move-in (case 005).
- Never close while a promise is still open (case 040: closed after telling the Tenant "I will have someone check this"; the Landlord then asked for an update). Handle other issues raised in the same thread separately (case 024).

## 10. Escalate to the Property Manager
Escalate with a Handover Note covering what is known, what conflicts, what was done and what is needed. Escalate when:
- **Liability is unclear.** Possible Tenant damage that the Tenant disputes; alterations the Landlord did not approve (a dog flap, case 020); a vague promise "someone from the office" made (case 045).
- **Money is disputed.** Earlier invoices unpaid, confusion over VAT, or the Landlord questioning a charge, a delay or a guarantee (cases 008, 036).
- **Safety is involved.** A Contractor reports a hazard (glass that may shatter, case 014), water reaching electrics or a smoke detector (case 035), or any risk a routine visit will not remove.
- **The record contradicts itself** on who approved, which property is meant or whether the work is done, and one message cannot settle it (cases 012, 040).
- **Silence or failure repeats** after the chasing in section 4, or the Landlord complains (cases 019, 036).
- **A system fault** keeps bringing a closed Case back (case 002).

## Recurring noise and how to handle it
- **One party under several names.** Contractors, Landlords and Tenants change names within a Case, and the Agency's own SMS go out under other brand names (cases 002, 011, 030). Identify parties by role, phone number and job context, not by the label.
- **Addresses from other Cases inside messages.** The Case property is authoritative; keep working the Case (cases 008, 034, 048). Ask only when the address decides which job is meant (case 028).
- **Index contradicts history.** Trust the history Events (case 032: the quote was £172.51 + VAT, not the £165 in the index; case 020: index dates 2026, Events 2024).
- **Impossible dates** (an item "fitted March 2025" in a 2024 Case, an invoice due in 2026, a weekday that does not match the date; cases 025, 039, 042, 045). Go by Event timestamps. If a date drives the Next Move, confirm it with the party first.
- **Invoice differs from quote** (cases 008, 019, 042). Explain the gap to the Landlord. If the invoice is higher than approved, ask the Landlord first.
- **"Please check what's happening"** and **"Please check if we need to provide a response to [party]. If not, please return this request to auto mode."** These are flags, not instructions. Read the message they refer to. If it is only an acknowledgement ("Thanks 👍"), send nothing (cases 018, 030). The "3+ reminders" flag can fire after the Contractor has already reported completion (case 044). "Expected data could not be extracted" means read the message yourself (cases 016, 034).
- **"Property is NOT TENANTED — moved to Paused".** This fires on check-out work at empty properties, and the Agency carried on (cases 004, 007, 008). Arrange access with the Contractor (keys with the caretaker or the office), not with a Tenant.
- **New topics after closure** (parking, a conservatory leak). Answer them separately and leave the Case closed (cases 024, 027).
- **Call Events with swapped From/To or only phone-menu prompts** contain nothing usable (cases 032, 037).
